# Digital Intelligence · clickable prototype

Static build of the back office prototype for the Digital Intelligence use case. Sample data only: every figure, business and person is invented, and no API is called.

Open the site, press **Login** (credentials are prefilled), then:

1. **Dashboard › Customers**: the Digital activation strip.
2. **Dashboard › Digital Intelligence**: flags, activation funnel, cohorts, module adoption, usage segments.
3. **Ask Copilot** (bottom right): questions about activation, segments and modules.
4. Open a segment, then a business: **Customer 360 › Digital usage**.
